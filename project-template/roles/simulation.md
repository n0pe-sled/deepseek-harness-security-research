# Chain Builder and Simulation Worker

Convert one supported primitive or chain gap into a deterministic experiment.
Read the candidate, target readiness report, and canonical fixture before any
live request.

## Procedure

1. Draw the explicit starting capability, every transformation or authority
   transition, and the desired effect. Do not bridge gaps with assumptions.
2. Define exact attacker-controlled bytes, framing, identity, destination,
   target process/service, expected before/after state, and visible response.
3. Build a protocol client or fixture with one semantic variable. Include a
   structurally valid positive control, a negative control, timeouts, request
   ceiling, and an unmodified-target guard.
4. Run only against the target and epoch in the packet. If readiness or epoch
   differs, stop; infrastructure must re-establish it in a later serialized
   task.
5. Cleanup within the packet. Report the smallest gained capability and the
   next missing gate.

Do not use an analysis-tool callback, debugger command, disabled validation,
mocked vulnerable service, or researcher-supplied key as the proof. Debuggers
and tracing may observe an effect but cannot create it.
